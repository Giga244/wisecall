# Fonts

Self-hosted (the Content-Security-Policy allows fonts from this site only). Variable-weight WOFF2 subsets from the Fontsource packages
`@fontsource-variable/inter`, `@fontsource-variable/manrope` and `@fontsource-variable/noto-sans-georgian` (v5.3.0).

| File | Font | Used for | Licence |
|---|---|---|---|
| `inter-latin.woff2` | Inter (The Inter Project Authors) | Latin text | SIL Open Font License 1.1 |
| `manrope-latin.woff2` | Manrope (The Manrope Project Authors) | Latin headings | SIL Open Font License 1.1 |
| `noto-sans-georgian.woff2` | Noto Sans Georgian (The Noto Project Authors) | Georgian text and headings | SIL Open Font License 1.1 |
| `noto-sans-georgian-latin-ext.woff2` | Noto Sans Georgian | Extended Latin, including the lari sign ₾ | SIL Open Font License 1.1 |
