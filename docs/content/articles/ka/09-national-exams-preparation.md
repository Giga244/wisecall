# ეროვნული გამოცდები: როგორ მოემზადო და სწორად აირჩიო უნივერსიტეტი

ეროვნული გამოცდები ბევრი ოჯახისთვის წლის მთავარი მოვლენაა. სტრესი გასაგებია — შედეგი განსაზღვრავს, სად და რა დაფინანსებით
ისწავლი. მაგრამ სწორი გეგმით მზადება ბევრად მართვადი ხდება. ამ სტატიაში განვიხილავთ, როგორ დაგეგმო წელი, როგორ აირჩიო საგნები
და უნივერსიტეტი, და რას მიაქციო ყურადღება რეგისტრაციისას.

> გამოცდების წესები, საგნები, რეგისტრაციის ვადები და გრანტის პირობები ყოველწლიურად შეიძლება შეიცვალოს. ერთადერთი ოფიციალური
> წყაროა შეფასებისა და გამოცდების ეროვნული ცენტრი (naec.ge). ყოველთვის იქ გადაამოწმე.

## 1. გაიგე წესები თავიდანვე

მზადების დაწყებამდე naec.ge-ზე გაარკვიე:

- რომელი საგნებია სავალდებულო და რომელი — არჩევითი;
- რომელი საგნები მოითხოვება შენთვის სასურველ ფაკულტეტზე (ეს უნივერსიტეტის და პროგრამის მიხედვით განსხვავდება);
- როგორ ითვლება სახელმწიფო სასწავლო გრანტი და რა დონის შედეგია საჭირო;
- რეგისტრაციის ვადები და წესი — რეგისტრაციის გაცდენა ძალიან ძვირი შეცდომაა.

თუ ასევე აბარებ უცხოეთში, გაარკვიე, რა მოთხოვნები აქვთ იქ — ზოგჯერ ეროვნული გამოცდის შედეგი საერთოდ არ მოითხოვება, ზოგჯერ კი
სხვა გამოცდა (მაგალითად, SAT ან ენის სერტიფიკატი) სჭირდება.

## 2. აირჩიე მიმართულება და უნივერსიტეტი

გადაწყვეტილება მხოლოდ „სად მიმიღებენ“ ნუ იქნება. იფიქრე:

- რა გაინტერესებს და რა გამოგდის — რომელ საგნებზე ხარჯავ დროს სიამოვნებით;
- როგორია პროფესია რეალურად — ესაუბრე ამ სფეროში მომუშავე ადამიანს;
- პროგრამის შინაარსი — საგნები, პრაქტიკა, გაცვლითი პროგრამები; ნახე უნივერსიტეტის საიტზე;
- აკრედიტაცია — შეამოწმე განათლების ხარისხის განვითარების ეროვნულ ცენტრში (eqe.ge);
- ღირებულება და დაფინანსების შესაძლებლობები.

## 3. შეადგინე მზადების გეგმა

1. **დიაგნოსტიკა.** გააკეთე წინა წლების ტესტი თითოეულ საგანში (naec.ge-ზე ქვეყნდება ნიმუშები და წინა წლების ტესტები). ნახე, სად
   ხარ ახლა და სად გინდა იყო.
2. **თემების სია.** თითოეული საგნისთვის ჩამოწერე თემები და მონიშნე: ვიცი / ნაწილობრივ / არ ვიცი.
3. **კვირის განრიგი.** რეალისტური — სკოლასთან, სხვა საქმეებთან და დასვენებასთან ერთად. ყოველდღე ცოტა სჯობს ერთ დღეს ბევრს.
4. **რეგულარული ტესტები.** ყოველ 2–4 კვირაში ერთი სრული ტესტი დროის შეზღუდვით — რომ დროის მართვაც ივარჯიშო.
5. **შეცდომების რვეული.** ყოველი შეცდომა ჩაწერე — რატომ დაუშვი და რა არის სწორი. გამოცდის წინ ეს შენი ყველაზე ღირებული მასალაა.

## 4. რეპეტიტორი თუ დამოუკიდებლად?

რეპეტიტორი არ არის სავალდებულო, მაგრამ შეიძლება დაგეხმაროს სტრუქტურით, უკუკავშირით და მოტივაციით. თუ ირჩევ:

- ჰკითხე მეთოდზე — როგორ ამოწმებს პროგრესს, რას აძლევს დავალებად;
- სცადე ერთი-ორი საცდელი გაკვეთილი;
- მხოლოდ „ჩააბარებინე“ დაპირებას ნუ ენდობი — ნახე მისი მოსწავლეების რეალური გამოცდილება.

დამოუკიდებლად მზადებაც შესაძლებელია, თუ დისციპლინა გაქვს: ოფიციალური ნიმუშები, სახელმძღვანელოები და უფასო ონლაინ მასალები.
მთავარია, რომ ვიღაცამ შეამოწმოს შენი ესე და წერითი დავალებები — მაგალითად, მასწავლებელმა.

## 5. პრიორიტეტების შევსება

როცა პრიორიტეტებს ავსებ, ფრთხილად იყავი: ეს ისეთივე მნიშვნელოვანია, როგორც გამოცდა.

- წაიკითხე naec.ge-ზე, როგორ ხდება ჩარიცხვა პრიორიტეტების მიხედვით;
- ჩაწერე პროგრამები **ნამდვილი სურვილის** მიხედვით;
- შეამოწმე, რომ შერჩეული საგნები ყველა პროგრამას შეესაბამება;
- შეავსე დროულად და შეამოწმე ორჯერ — ზოგჯერ შეცდომის გასწორება შეუძლებელია.

## 6. ჯანმრთელობა და სტრესი

- ძილი არ არის დროის დაკარგვა — მეხსიერება ძილის დროს მუშაობს;
- ფიზიკური აქტივობა, თუნდაც გასეირნება, სტრესს ამცირებს;
- მშობლებთან ისაუბრე მოლოდინებზე — წნეხის შემცირება ხშირად შედეგს აუმჯობესებს;
- თუ შფოთვა ყოველდღიურობას ხელს უშლის, ესაუბრე ფსიქოლოგს — ეს ნორმალურია.

## სავარაუდო გრაფიკი

| როდის | რა გააკეთო |
|---|---|
| წინა ზაფხული / შემოდგომა | წესების გაცნობა, მიმართულების არჩევა, დიაგნოსტიკური ტესტები, გეგმა |
| შემოდგომა–ზამთარი | სისტემური მზადება, ყოველთვიური სრული ტესტი |
| რეგისტრაციის პერიოდი | რეგისტრაცია naec.ge-ს მითითებით — ვადა გადაამოწმე |
| გაზაფხული | ტესტები დროის შეზღუდვით, შეცდომების გამეორება |
| გამოცდების შემდეგ | პრიორიტეტების ფრთხილი შევსება ოფიციალური ვადებით |

## მშობლებისთვის: როგორ დაეხმაროთ

მშობლის როლი დიდია, მაგრამ დახმარება ზოგჯერ წნეხად იქცევა. რამდენიმე რჩევა:

- **დაეხმარეთ გეგმით, არა კონტროლით** — ერთად შეადგინეთ განრიგი, მაგრამ ყოველ საათს ნუ შეამოწმებთ.
- **ფაკულტეტი არჩიოს მოსწავლემ** — თქვენი გამოცდილება ღირებულია, მაგრამ პროფესიას ის ისწავლის.
- **ნუ შეადარებთ სხვებს** — „მეზობლის შვილმა ამდენი აიღო“ მოტივაციას არ ზრდის.
- **იზრუნეთ საფუძველზე** — ძილი, კვება, მშვიდი გარემო სახლში.
- **ფინანსური საკითხები წინასწარ განიხილეთ** — რა მოხდება, თუ გრანტი არ იქნება ან ნაწილობრივი იქნება; ეს მოსწავლეს გაურკვევლობას
  უხსნის.
- **ოფიციალური ინფორმაცია ერთად წაიკითხეთ** — naec.ge-ზე წესებსა და ვადებს ორი ადამიანი უფრო ადვილად შეამოწმებს.

## ხშირი შეცდომები

- **რეგისტრაციის ან პრიორიტეტების ვადის გაცდენა.**
- **მხოლოდ თეორიის კითხვა** ტესტების ამოხსნის გარეშე.
- **ფაკულტეტის არჩევა სხვების აზრით** — შენ ისწავლი ამ პროფესიას წლების განმავლობაში.
- **ბოლო თვეში ყველაფრის სწავლა** — დაღლილობა შედეგს აუარესებს.

## თუ შედეგი არ გამოვიდა ისე, როგორც გინდოდა

ეს არ არის დასასრული. შეგიძლია გაარკვიო, არსებობს თუ არა შედეგის გასაჩივრების შესაძლებლობა და ვადა (naec.ge), განიხილო სხვა
პროგრამები ან უნივერსიტეტები, პროფესიული განათლება, ან მომავალ წელს ხელახლა ჩაბარება უკეთესი გეგმით. ბევრი წარმატებული ადამიანი
პირველივე ცდაზე არ მოხვდა იქ, სადაც უნდოდა. მთავარია, გაანალიზო, რა არ იმუშავა, და შემდეგი ნაბიჯი მშვიდად დაგეგმო.

## ჰკითხე მას, ვისაც ეს უკვე გაუკეთებია

ზოგჯერ ერთი საუბარი ათ სტატიაზე მეტს აძლევს: როგორ დაგეგმა მზადება მოსწავლემ, რომელმაც მაღალი ქულა აიღო, რას ურჩევს
გამოცდილი მასწავლებელი შენს კონკრეტულ საგანში, ან როგორია სწავლა იმ ფაკულტეტზე, რომელზეც ფიქრობ.
