# კონფიდენციალურობა და შენი პირადობის მონაცემები

**რა არასდროს გვაქვს**
- შენი **ბარათის ნომერი** — მას მხოლოდ ბანკის გვერდზე შეიყვან.
- **შენი დოკუმენტის ან სახის ფოტოები** — პირადობის შემოწმება ჩვენს ვერიფიკაციის პროვაიდერთან (Didit) ხდება და არა Wisecall-ზე.

**რას ვინახავთ და როგორ**
- პაროლს — მხოლოდ დაცული, ცალმხრივი ჰეშის სახით (მისი წაკითხვა არავის შეუძლია, ჩვენც კი).
- მენტორებისთვის, პირადობის შემოწმებიდან: შედეგს, დადასტურებულ სახელს, დაბადების თარიღსა და ქვეყანას (**დაშიფრულად**). დაბადების თარიღიდან მხოლოდ ინფორმაციას ვიყენებთ „18 წლის ან უფროსი“.
- IBAN-სა და ლიცენზიის ნომერს — **დაშიფრულად**. მათ მხოლოდ შენ და ჩვენი გუნდი ხედავთ; სიებში მხოლოდ ბოლო 4 სიმბოლო ჩანს.
- ატვირთულ დოკუმენტებს (ლიცენზია, დიპლომი) — დაშიფრულად, მხოლოდ ჩვენი გუნდისთვის ხელმისაწვდომს; ყოველი გახსნა აღირიცხება და **გადაწყვეტილებიდან 90 დღეში იშლება**.

**ვინ ხედავს შენს პროფილს.** თავად ირჩევ **პარამეტრებში → პროფილი**: ყველა, ან მხოლოდ ისინი, ვისთანაც კითხვა-პასუხი გქონია. სიაში დამატებული მენტორის პროფილი ყოველთვის საჯაროა. შენი ელფოსტა პროფილზე არასდროს ჩანს.

**ვინ გვეხმარება კიდევ** (ხელშეკრულების საფუძველზე): ჩვენი ბანკი (გადახდები), ვერიფიკაციის პროვაიდერი (პირადობის შემოწმება), ელფოსტის სერვისი, ჰოსტინგის პროვაიდერი და ხელოვნური ინტელექტის სერვისი, რომელიც ჩვენს გუნდს მენტორების განაცხადების წაკითხვაში ეხმარება. ხელოვნური ინტელექტი **არასდროს** იღებს პირადობის მონაცემებს, შენს ელფოსტას, ტელეფონს, საბანკო რეკვიზიტებს ან დოკუმენტებს.

**ქუქი-ფაილები.** მხოლოდ აუცილებელი: ავტორიზებულ მდგომარეობაში დარჩენისთვის, უსაფრთხოების ქუქი ყალბი ანგარიშების წინააღმდეგ და მოკლევადიანი ქუქი Google-ით შესვლისას. სარეკლამო ან თვალთვალის ქუქი-ფაილებს არ ვიყენებთ.

**შენი უფლებები.** შეგიძლია მოითხოვო შენი მონაცემების ასლი, გასწორება ან წაშლა. მოგვწერე **კონტაქტის** გვერდიდან. სრული ინფორმაცია კონფიდენციალურობის პოლიტიკაშია.
