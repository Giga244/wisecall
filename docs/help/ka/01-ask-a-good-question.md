# როგორ დავსვათ კარგი კითხვა

მენტორი წერილობით და **მხოლოდ ერთხელ** გპასუხობს, ამიტომ ყველაფერი, რაც მას სჭირდება, კითხვაში უნდა ეწეროს. კარგ კითხვაზე ბევრად უკეთეს პასუხს მიიღებ.

**წესები**
- მინიმუმ **50** და მაქსიმუმ **4 000 სიმბოლო**. ველის ქვეშ მრიცხველი გაჩვენებს, რამდენი გაკლია.
- დაწერე შენი სიტყვებით. ნუ ჩაწერ სხვის პერსონალურ მონაცემებს (სახელს, ტელეფონს, ჯანმრთელობის ინფორმაციას) მისი ნებართვის გარეშე.
- არაფერი უკანონო ან საზიანო.

**რა ხდის კითხვას კარგს**
1. **შენი სიტუაცია 2–3 წინადადებით.** სად ხარ ახლა და რა სცადე უკვე. „ჯუნიორ დეველოპერი ვარ თბილისში, Node.js-ში ერთი წლის გამოცდილებით.“
2. **მთავარი კითხვა — ერთხელ და ნათლად.** „შემდეგ Go ვისწავლო თუ Node.js-ში გავღრმავდე, რომ წელიწადში ბექენდის სამსახური ვიპოვო?“
3. **რა დაგეხმარება გადაწყვეტილების მიღებაში.** ბიუჯეტი, ვადა, შენთვის რა არის ყველაზე მნიშვნელოვანი.
4. **ერთ კითხვაში — ერთი თემა.** სამ სხვადასხვა კითხვაზე სამ მოკლე პასუხს მიიღებ. სჯობს, ცალ-ცალკე დასვა.

**აირჩიე შესაფერისი მენტორი.** წაიკითხე მისი წოდება, „ჩემ შესახებ“ და მიმოხილვები. მენტორი საკუთარი გამოცდილებიდან გპასუხობს, ამიტომ აირჩიე ის, ვისაც ზუსტად ის გაუკეთებია, რასაც კითხულობ.

**გახსოვდეს:** პასუხი გამოცდილებაზე დაფუძნებული რჩევაა და არა პროფესიული მომსახურება. ის არ არის სამედიცინო დიაგნოზი, იურიდიული დასკვნა ან ფინანსური რჩევა კონკრეტულად შენს შემთხვევაზე. საგანგებო ვითარებაში დარეკე 112-ზე.

კითხვის მონახაზი ინახება, სანამ ბანკის გვერდზე გადადიხარ და ბრუნდები — გადახდას თუ გააუქმებ, ტექსტი არ დაგეკარგება.
