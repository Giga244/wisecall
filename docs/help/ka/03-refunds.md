# თანხის დაბრუნება

**თანხა ავტომატურად, მოთხოვნის გარეშე გიბრუნდება, თუ:**
- მენტორი გადახდიდან **7 დღეში** არ გიპასუხებს;
- ახალი მენტორის პირველ პასუხებს შორის რომელიმეს ჩვენი გუნდი შემოწმებისას უარყოფს;
- მენტორის ანგარიში შეჩერდება მაშინ, როცა შენი კითხვა ჯერ კიდევ ღიაა.

ყოველთვის გიბრუნდება **სრული თანხა**, Wisecall-ის საკომისიოს ჩათვლით.

**პასუხის მიღების შემდეგ**
პასუხი უკვე გაწეული მომსახურებაა, ამიტომ თანხა არ ბრუნდება მხოლოდ იმიტომ, რომ არ მოგეწონა ან არ ეთანხმები. ამის ნაცვლად შეგიძლია გულწრფელი მიმოხილვა დატოვო. თანხას სრულად **გიბრუნებთ**, თუ პასუხი აშკარად სპამია, ცარიელია, სხვა თემას ეხება ან ჩვენს წესებს არღვევს. ამისთვის მოგვწერე პასუხის მიღებიდან **7 დღის განმავლობაში** — ღილაკით **საჩივარი** პასუხის ქვეშ ან **კონტაქტის** გვერდიდან.

**რამდენ ხანს გრძელდება?** დაბრუნებას ბანკს მაშინვე ვთხოვთ. თანხა იმავე ბარათზე ბრუნდება, რომლითაც გადაიხადე, და შენს ბანკს მის ასახვას რამდენიმე სამუშაო დღე შეიძლება დასჭირდეს ([CHECK: რამდენი დღე სჭირდება ჩვეულებრივ ჩვენს ბანკს]). დასრულებისას ელფოსტით გაცნობებთ. მანამდე კაბინეტში წერია „თანხა ბრუნდება“.

**სანამ გადახდას ბანკში გაასაჩივრებ, ჯერ ჩვენ მოგვწერე.** ასე, როგორც წესი, უფრო სწრაფია და პრობლემას მანამდე მოვაგვარებთ.

**ბოლოს არ გადაიხადე?** თუ ბანკის გვერდზე გააუქმე ან გადახდა ვერ შესრულდა, თანხა არ ჩამოგეჭრა — დასაბრუნებელიც არაფერია.
