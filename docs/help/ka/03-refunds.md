# თანხის დაბრუნება

**თანხა ავტომატურად, მოთხოვნის გარეშე გიბრუნდება, თუ:**
- მენტორი გადახდიდან **7 დღეში** არ გიპასუხებს;
- მენტორი შენს კითხვას **უარყოფს** (სცდება იმას, რაზეც კარგად უპასუხებს, ან ჩვენს წესებს ეწინააღმდეგება): მიზეზს დაინახავ;
- ახალი მენტორის პირველ პასუხებს შორის რომელიმეს ჩვენი გუნდი შემოწმებისას უარყოფს;
- მენტორის ანგარიში შეჩერდება მაშინ, როცა შენი კითხვა ჯერ კიდევ ღიაა.

ყოველთვის გიბრუნდება **სრული თანხა**, Wisecall-ის საკომისიოს ჩათვლით.

**პასუხის მიღების შემდეგ**
პასუხი უკვე გაწეული მომსახურებაა, ამიტომ თანხა არ ბრუნდება მხოლოდ იმიტომ, რომ არ მოგეწონა ან არ ეთანხმები: ამის სათქმელად გულწრფელი მიმოხილვა არსებობს. მაგრამ თუ პასუხი შენს კითხვას არ პასუხობს, არასწორია ან ზიანის მომტანი, სხვა თემაზეა ან უხეშია, გამოიყენე **პასუხთან დაკავშირებით პრობლემის შეტყობინება** შენს კაბინეტში, პასუხის წაკითხვიდან **7 დღეში**. ჩვენი გუნდის წევრი კითხვასაც და პასუხსაც წაიკითხავს და გადაწყვეტს: **სრული დაბრუნება**, **ნაწილობრივი დაბრუნება** ან **არანაირი**, და მიზეზს გეტყვის. მანამდე ამ კითხვის ანაზღაურება მენტორს შეჩერებული აქვს.

**რამდენ ხანს გრძელდება?** დაბრუნებას ბანკს მაშინვე ვთხოვთ. თანხა იმავე ბარათზე ბრუნდება, რომლითაც გადაიხადე; ამონაწერში როდის გამოჩნდება, შენი ბანკი წყვეტს (ხშირად რამდენიმე სამუშაო დღე). დასრულებისას ელფოსტას და დაბრუნების ქვითარს მიიღებ. მანამდე კაბინეტში წერია „თანხა ბრუნდება“.

**სანამ გადახდას ბანკში გაასაჩივრებ, ჯერ ჩვენ მოგვწერე.** ასე, როგორც წესი, უფრო სწრაფია და პრობლემას მანამდე მოვაგვარებთ.

**ბოლოს არ გადაიხადე?** თუ ბანკის გვერდზე გააუქმე ან გადახდა ვერ შესრულდა, თანხა არ ჩამოგეჭრა — დასაბრუნებელიც არაფერია.
