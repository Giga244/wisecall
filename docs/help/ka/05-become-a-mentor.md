# როგორ გავხდე მენტორი

განაცხადის შეტანა შეუძლია ნებისმიერს, ვინც 18 წლის ან უფროსია და რეალური, პრაქტიკული გამოცდილება აქვს. არ გჭირდება დამსაქმებელი, დიპლომი ან თანამდებობა: თვითნასწავლებს, ფრილანსერებსა და ბიზნესის მფლობელებს სიამოვნებით ველით.

**ნაბიჯები**
1. **შექმენი ანგარიში** და ელფოსტა 6-ნიშნა კოდით დაადასტურე.
2. **პარამეტრები → მენტორი:** ჩართე „მინდა კითხვებს ვუპასუხო“, აირჩიე სფერო და დააწესე ფასი (5–2 000 ₾ ერთ კითხვაზე) ან აირჩიე უფასოდ პასუხი.
3. **პარამეტრები → ვერიფიკაცია**, სამ ნაწილად:
   - **ვინაობა:** პირადობის დოკუმენტისა და სელფის სწრაფი შემოწმება ჩვენს ვერიფიკაციის პროვაიდერთან, ტელეფონით ან კომპიუტერით. იხ. „ვერიფიკაციის ეტაპები“.
   - **გამოცდილება:** ერთი ფორმა: შენი წოდება, სფერო, რამდენიმე სპეციალიზაციის ტეგი, გამოცდილების წლები, შენი ისტორია (100–1 500 სიმბოლო), **სანიმუშო პასუხი** (150–3 000 სიმბოლო) და **სულ მცირე ერთი მტკიცებულება** (ბმული შენს ნამუშევარზე, ვებგვერდი, LinkedIn, პუბლიკაცია, კომპანია, დიპლომი…).
   - **განხილვა:** დააჭირე **განსახილველად გაგზავნას**. ჯერ ავტომატური შემოწმება ტარდება, შემდეგ კი გადაწყვეტილებას ჩვენი გუნდის წევრი იღებს.
4. **პარამეტრები → ანაზღაურება:** მიუთითე ანგარიშის მფლობელის სახელი და შენი ქართული IBAN. **Wisecall-ზე მხოლოდ მაშინ გამოჩნდები, როცა დამტკიცებული იქნები და საბანკო რეკვიზიტებიც შენახული გექნება.**

თუ ბმულები წინასწარ მოამზადე, განაცხადს დაახლოებით 10 წუთი სჭირდება.

**მედიცინის, სამართლისა და ფინანსების** სფეროში საჭიროა მოქმედი ლიცენზიის ან რეგისტრაციის ნომერიც, რომელსაც ჩვენი გუნდი ოფიციალურ რეესტრში ამოწმებს.

**უარი მიიღე?** ამ გადაწყვეტილებას ყოველთვის ადამიანი იღებს და მიზეზსაც გეუბნება. გამოასწორე, რაც მოგწერეს, და ხელახლა შეიტანე განაცხადი — შეზღუდვა არ არის. გადაწყვეტილების მიღებისთანავე ელფოსტით მოგწერთ.
