# როგორ გავხდე მენტორი

განაცხადის შეტანა შეუძლია ნებისმიერს, ვინც 18 წლის ან უფროსია და რეალური, პრაქტიკული გამოცდილება აქვს. არ გჭირდება დამსაქმებელი, დიპლომი ან თანამდებობა: თვითნასწავლებს, ფრილანსერებსა და ბიზნესის მფლობელებს სიამოვნებით ველით.

**ნაბიჯები**
1. **შექმენი ანგარიში** და ელფოსტა 6-ნიშნა კოდით დაადასტურე.
2. **შენი განაცხადი** (ღილაკი „გახდი მენტორი“, ან [განაცხადის გვერდი](/apply.html)), ხუთ მოკლე ნაბიჯად: შენ შესახებ (მოკლე აღწერა, სფერო, გამოცდილების წლები), შენი ისტორია (100–1 500 სიმბოლო), ფასი (5–2 000 ₾ ერთ კითხვაზე, ან უფასოდ პასუხი), შენი ნამუშევრის მტკიცებულება (სულ მცირე ერთი ბმული: ნამუშევარი, ვებგვერდი, LinkedIn, პუბლიკაცია, კომპანია, დიპლომი…) და პირადობის დოკუმენტისა და სელფის სწრაფი შემოწმება ჩვენს ვერიფიკაციის პროვაიდერთან. იხ. „ვერიფიკაციის ეტაპები“.
3. **გაგზავნე.** ჯერ ავტომატური შემოწმება ტარდება, შემდეგ კი გადაწყვეტილებას ჩვენი გუნდის წევრი იღებს.
4. **ანაზღაურების მონაცემები, თუ ფასს აწესებ:** **პარამეტრები → ანაზღაურება**, მიუთითე ანგარიშის მფლობელის სახელი და შენი ქართული IBAN. **Wisecall-ზე დამტკიცების შემდეგ გამოჩნდები; თუ ფასი გაქვს, საბანკო რეკვიზიტებიც შენახული უნდა იყოს.** მენტორს, რომელიც უფასოდ პასუხობს, საბანკო ანგარიში არ სჭირდება.

თუ ბმულები წინასწარ მოამზადე, განაცხადს დაახლოებით 10 წუთი სჭირდება.

**მედიცინის, სამართლისა და ფინანსების** სფეროში საჭიროა მოქმედი ლიცენზიის ან რეგისტრაციის ნომერიც, რომელსაც ჩვენი გუნდი ოფიციალურ რეესტრში ამოწმებს.

**უარი მიიღე?** ამ გადაწყვეტილებას ყოველთვის ადამიანი იღებს და მიზეზსაც გეუბნება. გამოასწორე, რაც მოგწერეს, და ხელახლა შეიტანე განაცხადი — შეზღუდვა არ არის. გადაწყვეტილების მიღებისთანავე ელფოსტით მოგწერთ.
