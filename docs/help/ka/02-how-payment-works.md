# როგორ ხდება გადახდა

1. **ფასს წინასწარ ხედავ.** თითოეული მენტორი ერთი კითხვის ფასს თავად ადგენს, ლარში (5 ₾-დან 2 000 ₾-მდე). ეს სრული თანხაა.
2. **იხდი ბარათით, ბანკის დაცულ გვერდზე.** კითხვის გაგზავნის ღილაკზე დაჭერისას გადადიხარ ჩვენი ბანკის საგადახდო გვერდზე (საქართველოს ბანკი ან თიბისი ბანკი). Wisecall შენი ბარათის ნომერს ვერ ხედავს და არ ინახავს.
3. **კითხვა მენტორს მხოლოდ მაშინ ეგზავნება, როცა ბანკი გადახდას დაადასტურებს.** Wisecall-ზე დაბრუნებიდან ჩვეულებრივ რამდენიმე წამი სჭირდება. თუ გვერდზე წერია, რომ ჯერ კიდევ ელოდება, ცოტა ხანს დატოვე გახსნილი — ბანკს თავად გადაამოწმებს.
4. **გადახდის დასასრულებლად 30 წუთი გაქვს.** თუ გააუქმებ, გადახდა ვერ შესრულდება ან ბოლომდე არ მიიყვან, **თანხა არ ჩამოგეჭრება** და კითხვა არ გაიგზავნება. შეგიძლია მაშინვე თავიდან სცადო — ტექსტი ველში დაგხვდება.

**სად ვნახო ჩემი კითხვა?** **პირად კაბინეტში → ჩემი კითხვები**. დაუსრულებელი გადახდები დამალულია ღილაკის „დაუსრულებელი გადახდების ჩვენება“ ქვეშ და 7 დღეში იშლება.

**ვის ერიცხება თანხა?** სანამ მენტორი გიპასუხებს, თანხა Wisecall-თან ინახება. მენტორი თავის წილს (80%-ს) მოგვიანებით, პასუხის შემდეგ იღებს (იხ. „როგორ იღებენ მენტორები ანაზღაურებას“). თუ მენტორი დროულად არ გიპასუხებს, მთელი თანხა გიბრუნდება.

**ვალუტა.** იხდი ლარში. თუ შენი ბარათი სხვა ვალუტაშია, კონვერტაციას შენი ბანკი აკეთებს და ეს ჩვენზე არ არის დამოკიდებული.

**გაშვებამდე:** სანამ Wisecall წინასაგაშვებო ეტაპზეა, გადახდა ჯერ შეუძლებელია. შეგიძლია ჩაეწერო მოლოდინის სიაში — ერთხელ მოგწერთ ელფოსტით.
