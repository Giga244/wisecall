# შენი კაბინეტი: რას ნიშნავს თითოეული სტატუსი

**ჩემი კითხვები**
| სტატუსი | მნიშვნელობა |
|---|---|
| გადახდის მოლოდინში | ბანკში გადახდა ბოლომდე არ მიგიყვანია (ან ჯერ კიდევ დასტურდება). თანხა ჯერ არ ჩამოგეჭრა |
| გადახდილია — პასუხის მოლოდინში | კითხვა მენტორთან არის. მთვლელი დარჩენილ დღეებს გაჩვენებს (სულ 7) |
| მოწმდება | მენტორმა გიპასუხა; ეს მისი პირველი 5 პასუხიდან ერთ-ერთია და ჯერ ჩვენი გუნდი კითხულობს (24 სთ-მდე) |
| პასუხგაცემული | წაიკითხე პასუხი და შეაფასე მენტორი |
| თანხა ბრუნდება | ბანკს თანხის დაბრუნება ვთხოვეთ; შენს ბანკს რამდენიმე სამუშაო დღე შეიძლება დასჭირდეს |
| თანხა დაბრუნებულია | თანხა შენს ბარათზე დაბრუნდა |

გაუქმებული ან წარუმატებელი მცდელობები („გადახდა არ დასრულებულა“) დამალულია ღილაკის **დაუსრულებელი გადახდების ჩვენება** ქვეშ და 7 დღეში იშლება. მათში თანხა არ ჩამოგეჭრა.

**კითხვები ჩემთვის** (მენტორებისთვის): ახალი გადახდილი კითხვები ვადით და პასუხის ფორმა. **შემოსავალი** (მენტორებისთვის): შეკავებული, გადასახდელი და გადარიცხული თანხები და გადარიცხვების ისტორია.

ყველაფერი მნიშვნელოვანი ელფოსტითაც მოგივა, შენ მიერ არჩეულ ენაზე.
