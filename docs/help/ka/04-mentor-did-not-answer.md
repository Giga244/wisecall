# რა ხდება, თუ მენტორი არ მიპასუხებს?

მენტორს **7 დღე** აქვს გადახდის დადასტურებიდან. კაბინეტში კითხვასთან დარჩენილი დროის მთვლელს ხედავ.

- ვადის ამოწურვამდე დაახლოებით **2 დღით ადრე** მენტორი შეხსენებას იღებს ელფოსტით.
- თუ 7 დღის გასვლისას პასუხი ჯერ კიდევ არ არის, **თანხა ავტომატურად და სრულად გიბრუნდება**. არაფრის გაკეთება არ გჭირდება — ელფოსტითაც გაცნობებთ.
- კითხვაზე, რომლის თანხაც უკვე დაბრუნდა, მენტორი ვეღარ გიპასუხებს, ასე რომ, ორჯერ არასდროს გადაიხდი და უსასრულოდ ლოდინი არ მოგიწევს.

**პასუხი „მოწმდება“?** ახალი მენტორის პირველ 5 პასუხს, სანამ შენ დაინახავ, ჩვენი გუნდი კითხულობს. ამას მენტორის პასუხიდან **24 საათამდე** შეიძლება დასჭირდეს. როგორც კი წაკითხვა შეგეძლება, ელფოსტით გაცნობებთ. თუ გუნდი პასუხს უარყოფს, თანხა სრულად დაგიბრუნდება.

**კიდევ ელოდები და ღელავ?** ჯერ კაბინეტში ნახე: სტატუსი გეტყვის, კითხვა გადახდილია, პასუხგაცემულია, მოწმდება თუ თანხა დაბრუნდა. თუ რამე უცნაურად გეჩვენება, მოგვწერე **კონტაქტის** გვერდიდან და მიუთითე მენტორის სახელი და კითხვის დასმის თარიღი.
