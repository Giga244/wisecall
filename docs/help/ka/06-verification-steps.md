# ვერიფიკაციის ეტაპები და რატომ გვჭირდება

მყიდველები რეალულ გამოცდილებაში იხდიან, ამიტომ თითოეულ მენტორს გამოჩენამდე ვამოწმებთ. აი, თითოეული ეტაპი და რისთვის არის საჭირო.

| ეტაპი | რას აკეთებ | რატომ |
|---|---|---|
| **ელფოსტა** | შეიყვანე 6-ნიშნა კოდი, რომელიც გამოგიგზავნეთ | რომ დაგიკავშირდეთ და შენი მისამართით სხვამ ვერ ისარგებლოს |
| **პირადობა + სელფი** | ჩვენს ვერიფიკაციის პროვაიდერთან (Didit) დაასკანერე პირადობის მოწმობა ან პასპორტი და გადაიღე ცოცხალი სელფი | რომ დავრწმუნდეთ, რეალური ადამიანი ხარ და ის, ვინც ამბობ |
| **18+ ასაკი** | არაფერი — პირადობის დოკუმენტიდან იკითხება | მენტორი სრულწლოვანი უნდა იყოს |
| **სახელის დამთხვევა** | არაფერი, თუ პროფილზე სახელი დოკუმენტს ემთხვევა | მყიდველები შენს ნამდვილ სახელს ხედავენ. ქართული და ლათინური დაწერილობა (ნინო / Nino) ავტომატურად ედარება ერთმანეთს |
| **გამოცდილება** | ფორმა, სანიმუშო პასუხი და სულ მცირე ერთი მტკიცებულება | რომ დავინახოთ, შენი გამოცდილება რეალურია და სფეროს შეესაბამება |
| **ლიცენზია** (მედიცინა, სამართალი, ფინანსები) | ლიცენზიის ან რეგისტრაციის ნომერი, ზოგჯერ დოკუმენტიც | ეს სფეროები კანონით რეგულირდება |
| **განხილვა** | დაელოდე | ავტომატური შემოწმება (მათ შორის ხელოვნური ინტელექტის შეჯამება ჩვენი გუნდისთვის), შემდეგ კი ადამიანი იღებს გადაწყვეტილებას |

**კარგია, თუ იცი**
- **Wisecall შენი დოკუმენტის ან სახის ფოტოს არასდროს იღებს.** შემოწმებას ვერიფიკაციის პროვაიდერი ატარებს და გვატყობინებს შედეგს, შენს დადასტურებულ სახელს, დაბადების თარიღსა და ქვეყანას. დაბადების თარიღიდან მხოლოდ ინფორმაციას ვიყენებთ „18 წლის ან უფროსი: დიახ/არა“.
- ავტომატური შემოწმება ხსნის შენს მტკიცებულების ბმულებს და ამოწმებს, ჩანს თუ არა იქ შენი სახელი. ყველაზე მეტად გეხმარება ბმულები, სადაც შენი სახელი ან ბრენდი ნათლად ჩანს. მოერიდე ბმულების შემოკლების სერვისებს და სულ ახალ საიტებს.
- **უარს კომპიუტერი არასდროს ამბობს.** ყოველ უარს ადამიანი იღებს და მიზეზსაც გეუბნება.
- თუ რამე გაურკვეველია, შეიძლება **ერთი დამატებითი დოკუმენტი** გთხოვოთ. მას განაცხადში ატვირთავ.
- ატვირთული დოკუმენტები დაშიფრულია, მათ მხოლოდ ჩვენი გუნდი ხსნის და გადაწყვეტილებიდან 90 დღეში იშლება.
- გაშვებამდე პირადობის ეტაპზე შეიძლება ეწეროს „პირადობის შემოწმება მალე გაიხსნება“ — მანამდე დანარჩენი შეგიძლია შეავსო.
