# წესები მენტორებისთვის

**პასუხის გაცემა**
- უპასუხე გადახდიდან **7 დღეში**. წინააღმდეგ შემთხვევაში მყიდველს თანხა ავტომატურად დაუბრუნდება და ამ კითხვაზე ანაზღაურებას ვერ მიიღებ.
- პასუხს **ერთხელ** იძლევი. ის უნდა შეიცავდეს მინიმუმ **150 სიმბოლო** ნამდვილ ტექსტს და გაგზავნის შემდეგ მისი რედაქტირება შეუძლებელია. არ იჩქარო და ჯერ გადაამოწმე.
- შენს **პირველ 5 პასუხს**, სანამ მყიდველი დაინახავს, ჩვენი გუნდი კითხულობს (24 საათამდე).
- თუ მყიდველი ერთ უფასო დამატებით კითხვას დაგისვამს, უპასუხე **3 დღეში**.
- რა ხდის პასუხს სასარგებლოს, მაგალითით: [როგორ დავწეროთ კარგი პასუხი](/ka/help/write-a-great-answer).

**გულწრფელობა**
- განაცხადში ყველაფერი სიმართლე უნდა იყოს და შენ უნდა გეკუთვნოდეს: წოდება, გამოცდილება, მტკიცებულებები.
- დარჩი შენი რეალური გამოცდილების ფარგლებში. თუ კონკრეტულ შემთხვევას ექიმი, იურისტი ან ფინანსური მრჩეველი სჭირდება, პასუხში ეს პირდაპირ თქვი.
- პასუხი გამოცდილებაზე დაფუძნებული რჩევაა და არა დიაგნოზი, იურიდიული დასკვნა ან პირადი საინვესტიციო რეკომენდაცია.

**არასდროს**
- არ სთხოვო მყიდველს, რომ Wisecall-ის გარეთ გადაგიხადოს ან დაგიკავშირდეს;
- არ გაასაჯაროო მყიდველის კითხვა და არ გადასცე სხვას მისი პერსონალური მონაცემები;
- არ გააგზავნო სპამი და არ დაარეკლამო შეუსაბამო მომსახურება;
- არ ითხოვო, იყიდო ან გაცვალო შეფასება და ნუ მოახდენ ზეწოლას, რომ ვინმემ შეფასება შეცვალოს.

**რა ხდება წესების დარღვევისას.** მყიდველს შეუძლია მენტორზე საჩივრის გაგზავნა. ყოველ საჩივარს ჩვენი გუნდი განიხილავს. შეიძლება მენტორი საიტიდან მოვხსნათ, მის ღია კითხვებზე თანხა დავაბრუნოთ და გადარიცხვები შევაჩეროთ — ყოველთვის მიზეზის მითითებით. თუ ლიცენზიას ვადა გაუვა, საიტიდან იხსნები, სანამ განახლებული ლიცენზია არ დამტკიცდება.

**გადასახადების** გადახდა შენი პასუხისმგებლობაა.
