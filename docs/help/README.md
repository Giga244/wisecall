**Important differences between the brief and the code** (the articles follow the code):
- **"Balance, withdraw from 100 ₾"** does not exist. Mentors have no withdraw button and no minimum: an admin pays out everything that is
  payable by manual bank transfer (article 07 says so and is marked `[CHECK]`).
- **Deleting an account** has no button: people write to support (article 12, `[CHECK]`).
- The Georgian **Settings → Payouts** tab is labelled „გადახდები“ (payments), the same word as buyers' payments. The articles quote it as it
  is; `docs/TODO-QUALITY.md` proposes „ანაზღაურება“.
